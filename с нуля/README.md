# Python с нуля: практикум

Комплекс заданий «изучение через практику»: от первой строчки кода
до уверенного решения классических алгоритмических задач — числа, сортировки,
стеки, очереди, списки, деревья.

Объектно-ориентированное программирование и паттерны проектирования
в этот комплекс **не входят** — они изучаются отдельно по другим материалам.

Среда работы — **PyCharm** под Windows (в том числе на терминальном сервере
Windows Server 2022, где за одной машиной работают несколько студентов).

# Как работать с курсом

Это главный документ курса: прочитайте его целиком один раз — дальше будет
просто. Если что-то забудете, возвращайтесь к разделу «Частые проблемы».

## Что понадобится

- Компьютер с Windows и установленный **PyCharm** (подойдёт бесплатный
  Community; на учебном сервере он уже установлен).
- **Python 3.10** или новее.
- **Своя папка** для курса. На сервере, где работают несколько студентов,
  обязательно держите курс в своей личной папке, например
  `C:\Users\<ваш_логин>\python-course`. Папка на рабочем столе тоже подойдёт —
  главное, чтобы она ваша: в общей папке студенты затирают файлы друг друга.

## Шаг 1. Откройте курс в PyCharm (делается один раз)

1. Запустите PyCharm. Если откроется приветственное окно — нажмите **Open**;
   если уже открыт какой-то проект — **File → Open...**
2. Укажите папку `python-course` и нажмите OK. Если PyCharm спросит
   «Trust project?» — доверяйте (**Trust**).
3. Проверьте интерпретатор Python:
   **File → Settings → Project: python-course → Python Interpreter**.
   Вверху в поле «Interpreter» должен быть указан Python 3.10 или новее.
   Если поле пустое — нажмите **Add Interpreter → Add Local Interpreter →
   Virtualenv → OK**: PyCharm создаст личное окружение `.venv` внутри проекта.
   На многопользовательском сервере это безопасно: ваше окружение никому
   не мешает.
4. Установите инструмент автопроверки. Внизу нажмите вкладку **Terminal**
   (или **Alt+F12**) и наберите команду (копировать — **Ctrl+V**, вставка
   в терминал работает):

   ```
   python -m pip install -r requirements.txt
   ```

   Дождитесь сообщения об успешной установке `pytest`. Если PyCharm наверху
   покажет жёлтую плашку «Install requirements» — можно нажать её вместо
   ручной команды, результат тот же.

## Шаг 2. Разберитесь, куда идти

Курс устроен как дорога со указателями:

```
трек 0 → трек 1 → трек 2
```

- **Трек 0** (`track0-pycharm/`) — практикум по среде: научиться запускать
  программы, отладчику и горячим клавишам. Без программирования как такового.
- **Трек 1** (`track1-basics/`) — основы языка: вывод, переменные, условия,
  циклы, строки, списки, словари, функции, исключения, файлы, генераторы.
- **Трек 2** — алгоритмическая практика: числа, поиск и сортировки, стек,
  очередь, связный список, деревья.

Трек состоит из **модулей** (папки `moduleNN-...`), модуль — из **задач**.
Задача — это обычный файл Python. Порядок движения простой: трек 0,
затем модуль 01 задача за задачей, затем модуль 02 и так далее. Порядок
важен: каждая задача опирается на навыки предыдущих.

У каждого модуля есть `README.md` — **шпаргалка**: короткая теория с
примерами и таблица задач. Читайте её перед решением, подглядывайте во время.

## Шаг 3. Решите первую задачу

Откройте `track1-basics/module01-first-steps/tasks/task01_hello.py`.
Вверху файла, в тройных кавычках, написано **условие** — что программа
должна сделать и пример вывода. Ниже — место для кода с пометкой `# TODO`.

Жизненный цикл любой задачи:

1. **Прочитайте условие** в начале файла. Найдите строку `TODO` — ваш код
   пишется там (пометку удалите, когда закончите).
2. **Напишите код.**
3. **Запустите программу сами**: кликните правой кнопкой по файлу задачи →
   **Run 'task01_hello'** (или **Shift+F10**). Если программа читает ввод —
   набирайте данные в поле внизу, в панели Run, и нажимайте Enter.
   Сверьте результат с примером из условия.
4. **Проверьте себя автотестом**: рядом с задачей лежит файл
   `test_task01_hello.py`. Правый клик по нему → **Run 'pytest in
   test_task01_hello'**. Внизу откроется панель тестов.
   - Всё **зелёное** — задача зачтена, переходите к следующей.
   - Есть **красное** — тест подскажет, что не так (см. ниже).
5. Наведите порядок: **Ctrl+Alt+L** (автоформатирование) и убедитесь, что
   PyCharm не подчёркивает ваш код жёлтым.

## Как запустить тесты (три способа)

- **Один тест-файл**: правый клик по `test_taskNN_*.py` → **Run 'pytest in ...'**
  или зелёная стрелка на полях рядом с именем теста.
- **Весь модуль сразу**: правый клик по папке `tasks` → **Run 'pytest in tasks'** —
  удобно, чтобы увидеть общую картину прогресса.
- **Терминал**: команда `python -m pytest` из папки модуля.

## Как читать результат теста

Откройте упавший тест в панели Run — там показано, **что ожидалось** и
**что получилось**. Например:

```
assert ['5'] == ['сумма 5']
E  AssertionError: assert ['сумма 5'] == ['5']
```

Слева от `==` — то, что напечатала ваша программа, справа — то, что ожидал
тест (или наоборот, смотрите на подписи слева в выводе pytest). Сравните
строки: обычно сразу видно лишнюю подпись, пропущенную строку или опечатку.

## Частые проблемы и решения

| Что видите | Почему | Что делать |
|---|---|---|
| Тест красный, «слева пустой список» `[]` | Программа ничего не вывела | Решение не написано или осталось на месте `TODO` |
| «Программа завершилась с ошибкой» + traceback | Во время работы произошло исключение | Прочитайте **последнюю** строку traceback: там тип ошибки и номер строки вашего файла |
| «Программа работала дольше 10 секунд» | Программа ждёт ввода, которого не будет | Вызовов `input()` больше, чем строк ввода в примере условия |
| Вывод «на глаз правильный», тест красный | Лишний текст: приглашения вида «Введите число:», лишние или переставленные строки | Сравните ваш вывод и ожидаемый построчно; приглашения выводать не нужно (если условие прямо не требует) |
| `ModuleNotFoundError: No module named 'coursekit'` | Тесты запущены не из проекта | Откройте в PyCharm всю папку `python-course` целиком, а не отдельную папку модуля |
| `'python' не является внутренней или внешней командой` | Терминал не видит Python | Откройте Settings → Python Interpreter и убедитесь, что интерпретатор выбран |
| `No module named pytest` | Не выполнен шаг 1.4 | `python -m pip install -r requirements.txt` |

## Правила курса

- **Ввод.** Каждый `input()` читает одну строку. Если условие не просит
  выводить приглашение («Введите число: ») — не выводите: тесты подают ввод
  вслепую, и лишний текст ломает сравнение.
- **Вывод.** Тесты сравнивают вывод построчно; концевые пробелы не важны,
  а вот порядок строк и подписи — важны.
- **Файлы тестов не изменяйте** — их правка ничего не даст: при защите
  преподаватель запускает свои копии тестов.
- Условие (текст в кавычках вверху файла) можно не удалять — код пишите
  под ним.
- Кодировка UTF-8 (в PyCharm по умолчанию).
- Задачи со звёздочкой ★ — повышенной сложности, не обязательны для зачёта
  модуля, но полезны для роста.

## Сколько времени занимает курс

- Модуль — примерно 2–4 практических занятия.
- Задача — от 5–10 минут (разминка) до часа (★).
- Застряли на одной задаче больше 15 минут — откройте шпаргалку модуля,
   попробуйте проверить свои догадки в Python Console (**View → Tool
   Windows → Python Console**), поставьте точку останова и пройдитесь
   отладчиком (этому учат в треке 0). Не помогло — спросите соседа или
   преподавателя: спросить — нормальная часть работы программиста.
